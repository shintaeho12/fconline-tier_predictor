# ⚽ FC 온라인 공식경기 AI 티어 유추 서비스 (FC Online AI Tier Predictor)

**NEXON Open API**를 통해 수집한 실제 공식경기(1vs1) 플레이 로그 데이터를 바탕으로, 유저의 플레이 스타일과 경기 효율성 지표를 분석하여 **상위권(챌린저 3부 이상) 여부를 예측하는 머신러닝 웹 서비스**입니다.

---

## 1. 프로젝트 기획 의도
League of Legends 등 인기 게임의 전적 검색 사이트들은 방대한 데이터를 기반으로 티어 상승 가능성을 예측해 줍니다. 이 프로젝트에서는 그 아이디어를 차용하여, **유저의 최근 공식경기 핵심 플레이 지표(패스, 슈팅, 점유율, 수비 효율)를 분석해 본인의 플레이 스타일이 상위권과 일반권 중 어느 쪽에 더 가까운지 진단하는 경량 AI 웹 서비스**를 구축했습니다.

---

## 2. 데이터 수집 및 전처리 전략
* **데이터 수집:** NEXON Open API를 활용해 공식경기(`matchtype=50`) 매치 상세 기록 및 유저 디비전 데이터 약 800~1,000건 수집 *(※ 넥슨 Open API 이용약관 준수를 위해 원본 CSV 데이터는 저장소에 포함하지 않았습니다.)*
* **타겟(Target) 정의:**
  * `1 (상위권)`: 챌린저 1부 이상 (`division <= 1100`)
  * `0 (일반권)`: 챌린저 2부 이하 (`division >= 1200`)
* **도메인 기반 노이즈 필터링 및 한계점 고려:**
  * 축구 전술의 다양성(극단적 점유율 축구 vs 선수비 후역습)을 보존하기 위해 통계적 이상치(IQR) 제거는 지양했습니다.
  * 대신 몰수승·몰수패(`matchEndType != 0`) 및 잠수(AFK) 경기(`pass_try < 20` 또는 `possession < 15`)만 엄격히 필터링하여 데이터 품질을 확보했습니다.
  * *(분석 한계)* API 일일 호출 한도로 인한 수집 표본의 제한과, 축구 게임 특성상 정해진 단일 승리 플랜이 존재하지 않는 변칙성으로 인해 일부 경기에서는 예측 오차가 발생할 수 있습니다.

---

## 3. 핵심 피처 엔지니어링 (파생 변수 9종)
경기 템포와 전술 차이를 보정하고 플레이의 정교함을 측정하기 위해 비율 중심의 파생 변수를 설계했습니다.

| 파생 변수명 | 계산 수식 | 설계 의도 |
| :--- | :--- | :--- |
| `through_pass_ratio` | `through_pass_try / pass_try` | 전체 패스 중 모험적인 스루패스 시도 비중 측정 |
| `pass_success_rate` | `pass_success / pass_try` | 빌드업 안정성 및 패스 미스 억제력 평가 |
| `effective_shoot_ratio` | `effective_shoot / shoot_total` | 무의미한 중거리 난사와 확실한 찬스 메이킹 구분 |
| `goal_conversion_rate` | `goal_total / effective_shoot` | 유효슈팅 대비 실제 득점 결정력 측정 |
| `tackle_success_rate` | `tackle_success / tackle_try` | 무분별한 헛태클 빈도 및 수비 정확도 파악 |
| `dribble_per_possession` | `dribble / possession` | 점유율 대비 볼 키핑 및 탈압박 적극성 측정 |

---

## 4. 모델 학습 및 데이터 분석 인사이트
* **모델 선정 및 검증:** 지공형 상위권과 역습형 상위권이라는 다중 패턴을 효과적으로 분기할 수 있는 **Random Forest Classifier**를 채택하고, `80:20` 층화 분할(`stratify=y`) 및 `5-Fold` 교차 검증을 수행했습니다.
* **핵심 발견 (EDA & Feature Importance):**
  * **변수 중요도 1·2위:** 직접 설계한 파생 변수인 **`through_pass_ratio`(스루패스 비중)**와 **`dribble_per_possession`(점유율당 드리블)**이 티어 구분의 가장 결정적인 변수로 선정되었습니다.
  * **티어별 플레이 패턴 차이:** 일반권 유저는 스루패스 시도 비중(중앙값 약 14.5%)이 높았으나 무리한 시도로 성공률이 낮았던 반면, **상위권 유저는 스루패스 비중을 약 12% 수준으로 절제하고 확실한 찬스에서만 시도해 높은 성공률을 기록하는 효율적인 경기 운영**을 보였습니다.

## 5. 주요 웹 서비스 기능 (`app.py`)
* **구단주 닉네임 실시간 분석:** 닉네임 입력 시 최근 정상 공식경기 최대 5판의 평균 스탯을 조회해 컨디션 기복을 보정하고, AI 예측 티어와 상위권 확률(%)을 산출합니다.
* **스탯 직접 입력 시뮬레이터:** API Key나 게임 계정이 없는 방문자도 슬라이더로 패스·슈팅·점유율 수치를 조절하며 AI 모델의 예측 변화를 실시간으로 체험할 수 있습니다.
